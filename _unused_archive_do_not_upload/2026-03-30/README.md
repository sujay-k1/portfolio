# Unused Archive

This folder contains files moved out of the active site on 2026-03-30.

Do not upload this folder to hosting if you want to keep the deployment lean.

## Categories

- `deployment-noise` (`56K`): local clutter and hosting backup artifacts such as `.DS_Store`, `.ftpquota`, and `.easyssl_backup/`.
- `legacy-pages` (`28K`): old page versions that are no longer referenced.
- `unpublished-home-variants` (`260K`): the unused `index-section3-vertical-first` variant and its private CSS/JS.
- `standalone-experiments` (`3.6M`): demo/prototype pages and their dedicated support files, including the old wave asset bundle.
- `unused-support-files` (`44K`): JS/CSS files that are not loaded by any remaining live page.
- `orphan-assets` (`320K`): root-level assets with no remaining references.
- `unused-duplicates` (`155M`): unreferenced duplicate media, mostly in `Biz2X-assets/` and `saison-omni-assets/`.

## Validation

- Remaining live files were checked for exact-path references to the moved files.
- No exact-path references to the archived files remain in the active site.
